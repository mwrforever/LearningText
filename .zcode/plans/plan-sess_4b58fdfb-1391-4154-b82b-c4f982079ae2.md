## 一、定位与已定决策

M5 已全绿交付。本批需求升级为新里程碑 **M6「产品化重构」**（吸收原 M6 打包发布能力），遵循宪法 C.7 谋→建→琢与 SDD 纪律。

已确认决策：**① 自绘集成标题栏**（titleBarStyle hidden + titleBarOverlay）；**② HTML 纯所见即所得**（不提供源码视图，CSS/JS 等非 HTML 文本仍用 CodeMirror）；**③ 设置页 = 编辑区特殊标签页**。

推演裁决（自主决策，spec 留痕）：树中点击媒体/HTML 文件一律开标签（媒体标签直接呈现，退役 D20 弱选中双源复杂度）；移除设置页「重建搜索索引」disabled 占位（需求 5，TASK.md 条目保留）；每标签独立 iframe 会话保活以保留原生撤销；数据目录迁移后必须 relaunch。

- **活动栏**（w-12 图标竖条）：资源树 Files、搜索 Search、回收站 Trash2；底部设置齿轮；选中态左侧 2px accent 指示条；图标钮一律带 `aria-label` + tooltip（可访问性红线）。
- **标题栏**：`titleBarStyle:'hidden'` + Windows `titleBarOverlay`（原生 ─□✕）；应用内渲染菜单（手拷 shadcn menubar registry 模板，EALLOWSCRIPTS 先例），菜单项仅现有 9 个命令 + 退出，加速器由保留的 `Menu.setApplicationMenu` 承载；`-webkit-app-region` drag/no-drag 划分；attachWindowCloseGuard 不变。
- **标签栏**：文件类型图标（FileText/FileCode/Image）、脏态小圆点（替代「未保存」文字）、hover 显 X 关闭钮、tooltip；MAX_TABS=20 保留。
- **欢迎页**：产品名 + 一句话定位、主操作（新建文件/导入/快速打开 Ctrl+P）、最近打开列表（settings.recent ≤10）、快捷键提示卡。
- **状态栏**：左＝保存态（脏点+文案）与节点统计；右＝主题三态循环切换钮 + 设置齿轮；保留 `lt-*` E2E 锚点并新增。
- **设置标签页**：特殊伪标签（不占 20 上限、Ctrl+W 关闭即回原标签）；左锚点导航（外观/编辑与预览/备份/**数据与存储(新)**/工作区）+ 右表单，全部图标化。
- 主题沿用现有语义 token（.dark 双主题），侧栏/活动栏用 muted 面 + border 分隔；布局记忆扩展 `shell.layout`（settings v3→v4 迁移链，增活动视图/侧栏态字段）。

## 三、所见即所得架构（批次②核心）

- **协议编辑桥**：`vfsProtocol.ts` 现有注入点扩展 PREVIEW_RECEIVER（data-lt-injected 标记 + 不参与 hash/ETag 纪律不变）；新增消息：父→子 `lt:edit-enable`（body contentEditable）/`lt:edit-disable`；子→父 `lt:doc-edit {html}`（iframe 内 input 去抖 ~200ms 上报）。序列化 = clone document → 摘除 [data-lt-injected] 与 contentEditable 属性 → `<!DOCTYPE html>` + outerHTML。CSP 不变（沙箱 opaque origin + allow-scripts 红线不破）。
- **保存接线**：SaveController 纯状态机零改动；`getDoc` 改读 HTML 标签的最新 doc-edit 缓存，`edit()` 由消息驱动；双计时器/写串行/Ctrl+S flush/关签 flush/关窗 guard 全复用；`vfs:write` 契约不变（无 sanitize 是既定安全边界）。
- **刷新抑制**：自己写引发的 `written` 广播命中编辑中标签 → 跳过 `location.replace`（护住光标/撤销）；外部写入（导入/还原）→ 重载 + toast「文档已在库中更新」。rev 状态机保留用于外部变更。
- **会话保活**：每个打开的 HTML 标签独立 iframe（非激活时隐藏），切签保留原生撤销；重启后撤销丢失（spec 明示取舍）。删除元素保存即永久失去（用户明示接受）。无格式工具栏。
- **退役**：scrollSync.ts、D14 滚动同步开关、编辑器→预览双槽桥、D20 媒体双源相关分支；`preview.debounceMs` 语义不变（写侧去抖），设置页改述为「保存/刷新去抖」。EditorPanel/CM 完整保留服务非 HTML 文本。

## 四、数据目录与打包（批次③）

- **指针文件** `<userData>/data-dir.json` `{root: string|null}`（缺失/损坏→回退默认+warn）；`app.ts` 装配链插入「读指针→resolveDataDir(effectiveRoot)」，其余服务全是路径注入零改动。**宪法 A.2-1 修订**（先记 CHANGELOG）：userData 专属子目录 → 「默认 userData 专属子目录，允许用户更改数据根；userData 直下仅允许指针文件」。
- **迁移 IPC**：新通道 `storage:get-info` / `storage:change-data-dir`（zod 契约 + Result DTO + E_STORAGE_* 错误码）；流程＝校验（非当前目录/可写）→ checkpoint(TRUNCATE) → 关库 → 复制 db+settings+backups → 原子写指针 → requestRelaunch；任一步失败不写指针、清理残留、照常 relaunch 走旧指针。复用 pickDirectories 登记簿范式。
- **安装位置**：electron-builder.yml 增 `nsis: { oneClick: false, allowToChangeInstallationDirectory: true }`；补 package.json `author`（既有 M6 阻塞项）。
- **设置页「数据与存储」分区**：当前目录路径展示 + 打开目录（shell:open-path 登记簿）+ 更改位置（选目录→AlertDialog 确认迁移内容→迁移→自动重启）。
