# LearningText 布局蓝图（M6 产品化重构 · 谋局定稿）

> 依据：`docs/superpowers/specs/2026-09-22-产品化UI重构-design.md` §2。本文档是「谋」段产物，建/琢阶段以此为唯一蓝图依据；四维验收（高级视觉/高级交互/流畅动画/高性能渲染）在「琢」段执行。
> 设计基调：VS Code 式专业工作台——信息密度克制、层次靠明度差而非装饰、图标先行、动效只做状态反馈（tw-animate-css 微动效，零运行时动画库）。

## 2. 分区规格

### 2.1 标题栏（lt-titlebar）

- 高 40px；整条 `app-region: drag`；菜单钮/交互件 `no-drag`。背景 `bg-muted`，与侧栏同面、以 1px border 与画布区分层。
- 左：应用标记（16px 图标 + 「LearningText」13px medium）；中：应用内菜单（文件 / 搜索 / 导入导出，menubar 组件，hover/focus 显触发态，下拉面板 tw-animate-css fade+zoom-in 100ms）；右：overlay 原生窗口控制钮（Windows/Linux），mac 无此区（系统红绿灯叠加）。
- 菜单树 = 既有 9 命令 + 退出，逐项带 lucide 图标与快捷键提示（`CommandShortcut` 样式）。**禁止占位项**。

### 2.2 活动栏（lt-activity-bar）

- 宽 48px；背景 `bg-muted`；图标钮 40×40（≥44px 热区含 padding），居中竖排。
- 顶部组：资源树 `Files`、搜索 `Search`、回收站 `Trash2`；底部组（`mt-auto`）：设置 `Settings`。
- 选中态：左侧 2px×20px accent 圆角指示条 + 图标 `text-foreground`；未选中 `text-muted-foreground`；hover 前景色过渡 100ms。

### 2.3 侧栏（lt-sidebar）

- 默认宽 25%（钳制 15%–60%），可折叠为 48px 窄条（折叠钮在面板头）。
- **折叠/展开（M8）**：单一常驻 `<aside>` 承载两态（原两元素三元互斥已退役——跨元素无插值起点），折叠态 `w-12` 与展开态内联百分比之间走 `transition-[width]` 180ms；窄条层绝对定位左缘、恒 48px，展开钮原地被逐帧揭示（不随侧栏横向平移）；内容层 100ms 淡出后随存在性计时（180ms）卸载——「折叠后内容真的卸载、订阅随卸载回收」语义不变；折叠/展开做焦点交接（折叠→窄条展开钮，展开→侧栏头折叠钮）。启动装载完成前不挂过渡（免「默认布局→记忆布局」的无动机动画）。
- 面板头 h-9：13px medium 标题 + 右侧图标操作钮组（图标 16px，`aria-label`+tooltip）：
  - 资源树：`FolderPlus` 新建目录 / `FilePlus` 新建文件 /（有选中时）`Pencil` 重命名、`FolderInput` 移动、`Trash2` 删除 / `PanelLeftClose` 折叠；
  - 搜索：`ArrowLeft` 返回资源树；输入框 + 类型 Select 保持；
  - 回收站：`ArrowLeft` 返回 / `Trash2` 清空（destructive 色，有条目才可用）。
- 树行：h-7 紧凑行高，类型图标（`Folder`/`FolderOpen`/`FileText`/`FileCode`/`Image`/`Music`）+ 名称；行尾 `MoreHorizontal` 行内菜单（hover/focus/open 显形，既有交互形态）；选中 `bg-accent`，move 目标 ring 提示（沿用现有语义）。

### 2.4 标签栏（lt-tabbar）

- h-36px；标签为「图标 + 名称(13px) + 脏点/关闭钮」胶囊；激活签 `bg-background` 与画布同面（VS Code 式融合），非激活签 hover 提亮。
- 脏态：名称右侧 6px destructive 实心圆点（hover 标签时切换为 `X` 关闭钮，VS Code 同款）；关闭钮 16px 图标。
- 右端固定：`+` 新建文件钮（`FilePlus`）、设置齿轮快捷钮。
- 类型图标映射：html→`FileText`、css/js/txt→`FileCode`、图片→`Image`、音频→`Music`、设置→`Settings`。

### 2.5 编辑画布（lt-canvas）

- 画布容器 `bg-background`；WYSIWYG iframe 撑满（文档自带样式，**不注入 UA 样式**）；**文档面基底为浏览器白**（iframe 元素 `bg-white`——子文档背景透明时应用底色会透出文档，保真修复见设计系统 §十二）；文档加载失败占位（`FileX` + 「文档加载失败」+ 重试钮）。
- 画布右下角浮动钮：`RotateCw`「从库重新加载」（tooltip；脏时 confirm）——外部变更显式拉取入口。
- 无标签 → 欢迎页：

```text
lt-welcome（居中 max-w-md，留白呼吸感）
  LearningText        ← 28px semibold
  HTML 文档管理与实时预览 · 所见即所得
  ┌ 新建文件 ┐ ┌ 导入… ┐ ┌ 快速打开 ⌘P ┐   ← 主操作钮（图标+文字）
  最近打开
   · 笔记一  /笔记/web/index.html    ← 点击开签，hover 提亮
   · …（≤10 条；空态「暂无最近打开的文档」）
  快捷键：Ctrl+S 保存 · Ctrl+P 快速打开 · Ctrl+Shift+F 全局搜索
```

### 2.6 状态栏（lt-statusbar）

- h-24px；`bg-muted`，12px 文本。左：脏态（destructive 圆点 +「有未保存更改」）或「已保存」+ ` · ` + 「N 个文档」；右：主题循环钮（`Sun`/`Moon`/`Monitor` 对应亮/暗/跟随系统，tooltip 注明当前态）+ `Settings` 齿轮。
- 全部钮 `aria-label` + tooltip；动效仅颜色过渡 100ms。

### 2.7 设置标签页

- 复用画布区；左侧 200px 锚点导航（图标 16px + 14px 文字：外观 `Palette` / 编辑与预览 `SlidersHorizontal` / 备份 `DatabaseBackup` / 数据与存储 `HardDrive` / 工作区 `History`），右侧表单 max-w-2xl，分组标题 15px medium + 分隔线；滑块/选择器沿用 shadcn 组件。
- 数据与存储分区：当前数据根（mono 13px 路径 + 「默认/自定义」badge）→「打开目录」`FolderOpen` /「更改数据位置…」`FolderInput`；迁移确认 AlertDialog 列明迁移内容（数据库、设置、备份）与「成功后自动重启」。

## 3. 主题与动效基线

- 语义 token 沿用 `styles/theme.css` 双主题；壳层面（标题栏/活动栏/侧栏/标签栏/状态栏）统一 `bg-muted` 系分层，画布与激活签 `bg-background`，层次=明度差。
- 动效：仅 tw-animate-css 微动效 + CSS 过渡（菜单 fade+zoom 100ms、面板切换 fade 100ms、标签关闭无动画）；全局过渡缓动 = ease-out（`theme.css` 的 `--default-transition-timing-function`），浮层/面板的 `animate-*` 入场显式 `ease-out`、出场显式 `ease-in`；`prefers-reduced-motion` 全降级（既有基线；退场动效类一律带终态保持，避免 reduced-motion 下动画瞬时结束后回弹滞留）。
- **侧栏折叠/展开例外条款（M8 复核）**：折叠几何走侧栏 `width` 过渡 180ms（单一 flex 行的单属性，非 grid 列模板；实测每帧强制布局 0.9–1.0ms 且与画布文档规模无关）——**拖拽路径与其余场景仍禁宽度/高度动画**（pointermove 直写内联宽度，pointerup 才持久化；拖拽期经 `data-dragging` 摘除过渡）。
- **按压微反馈（M8）**：`active:duration-0`（按下即时）+ 双档形态——纯图标钮 `active:scale-95`、含文字钮按压面深一档（`--accent-active` / primary-80）；**行级元素与 20px 级小钮不加按压态**（点击结果自证，详见设计系统 §6.2/§7.2）。
