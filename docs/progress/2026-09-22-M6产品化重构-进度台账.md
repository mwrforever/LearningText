## 纪律备注与偏差留证

- **start.bat ASCII 偏差**：全局规范「日志中文」与 zh-CN cmd 现实冲突（chcp 65001 下 UTF-8 批处理解析失步，echo 文本被执行为命令——首轮实跑实证）；功能正确性优先，bat 消息 ASCII 化，中文说明保留在 start.sh / README，已在文件头注释留证。
- **D7 落地修正（批次②）**：「从库重新加载」钮脏态**禁用**（tooltip 引导先保存/撤销），替代 spec 原「confirm 丢弃」设计——避免 SaveController 引入「重置脏态」旁路；spec §3.3 已同步回填。
- **上报时序修正（批次④）**：注入桥 doc-edit 由 200ms setTimeout 去抖改**逐输入即时上报**——E2E 探针实证沙箱 iframe 内计时器可被渲染器搁置无限期（>30s），上报尾部丢失即保存尾部丢失；写侧节奏由父窗 SaveController 全权承担。spec §3.1 已回填。
- **侧栏分隔条 0px 命中区缺陷（批次④修复）**：flex 行内分隔条无宽度类则 hit-test 永不命中（E2E 探针实证），补 `w-1 shrink-0`。
- **覆盖率存量缺口**（打磨代理 git stash 复跑定位）：批次③ app.ts storage 供给闭包与 dataDirMigration 部分分支未被覆盖——已补测 6 例回绿（不改生产代码）。

## 关键探针与决策证据

- **标题栏平台探针（2026-09-22，Windows 10.0.26200 / Electron 44.3.0）**：`titleBarStyle:'hidden'` + `titleBarOverlay:{height:40}` 下 `Menu.setApplicationMenu` 已设时 `win.isMenuBarVisible()===false`（原生菜单栏不渲染）；overlay 生效（`env(titlebar-area-height)=40` 可读）。结论已回填 spec §2.2。
- **v4 设置迁移**：`migrateV3ToV4` 平移树栏折叠/比例、活动视图回落 'tree'，编辑器/预览折叠字段退役（spec §2.7）。
- **迁移服务失败语义**（spec D9）：关库前校验失败=不重启库照常可用；关库后失败=清理残留+不写指针+照常重启走旧位置。单测 11 例覆盖（`tests/unit/storage/dataDirMigration.test.ts`）。
- **注入桥转义实证**：TS 单引号串内 `\"` 产出 `"`（非 `\"`），注入 JS 的内嵌双引号必须写 `\\"`；`new Function` 守卫捕获该缺陷并已修复。
- **刷新抑制为结构性保证（批次②）**：画布模型下不存在「写后重载」机制（PreviewPanel/refreshModel 已退役），written 广播对 HTML 画布天然无操作；外部变更唯一入口 = 手动重新加载钮。
