- 本会话实证教训: ① Tailwind v4 的 `group-data-[x=y]/name:transition-none` **静默不生成规则**（同名变体挂 `pointer-events-none` 却正常生成）——类串能力必须对构建产物 grep 核证；② `animate-out` 的 fill-mode 为 none，reduced-motion 把动画压到 0.01ms 后会**回弹成不透明并滞留整段 JS 计时**——退场一律带终态保持（transition 终态或 `fill-mode-forwards`）；③ 连点反向重启动画会从关键帧极值重播而闪断（animate-in/out 是两个动画名），需要续走的动效走 CSS transition；④ `createRoot(document.body)` 会清空 body 既有子元素并摘除同测试的容器，脱离文档的输入框 `focus()` 是空操作（失焦链静默不触发）——测试宿主须自持 div；⑤「失败态保留 + 重新聚焦」会变成焦点陷阱（用户离开后每次点击重发失败请求并抢回焦点）——失败应当收口而非滞留；⑥ state 化的在途守卫在同一任务内连发时读旧值会穿透，守卫用 ref；⑦ 新增守卫断言应临时移除被守卫的代码验证它会红（本会话对 pointercancel 实测）；⑧ 真机探针（Playwright 驱动 Electron）是复现「交互语义类」用户反馈的最短路径——jsdom 的焦点时序不可信。
