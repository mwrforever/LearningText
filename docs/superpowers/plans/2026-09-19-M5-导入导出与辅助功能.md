## Global Constraints（spec + 宪法摘录，每任务隐含遵守）

- 全部代码/注释/测试名/日志**中文**；UTF-8 无 BOM、LF 行尾；Conventional Commits 中文；每任务一次提交，测试与实现同提交。

- **渲染期禁写 ref**（75647f2 先例）：ref 赋值只能在 effect / 事件处理器内；惰性初始化单例豁免。
- CodeMirror 习语（A.1-9）：状态不可变、变更一律 dispatch/setState、view.destroy() 成对。
- 资源成对：订阅 cleanup、timer/dispose 清理、dialog 句柄——均须断言（M1–M4 教训）。
- **覆盖率门禁禁止下调**（A.6-3）：`src/main/**`（新增 io/**、backup/** 自动入核心 glob）100%、`src/shared/**`/`src/preload/**` 100%、全局 ≥80%；渲染层纯函数以单测 100% 支撑全局线。
- 无死分支纪律：不写运行时不可达分支；下标收窄用语义等价结构而非 `?? ''` 死侧。
- IPC 模式：渲染→主 invoke/handle；主→渲染 `webContents.send` + 可辨识联合；契约单一来源 `src/shared/`；两道校验（origin + zod safeParse）不豁免；渲染端不感知通道字符串。

- **E2E 稳定性红线（D23）**：不得破坏既有 aria-label/语义角色锚点；shadcn/Radix 自带 aria 是增强；迁移后 E2E 锚点以实际渲染 DOM 实测为准、逐处列对照表；布局语言变更只发生在批次⓪（Task 2）与⑧（Task 15）。

import { twMerge } from 'tailwind-merge';

export function cn(...inputs: ClassValue[]): string {
