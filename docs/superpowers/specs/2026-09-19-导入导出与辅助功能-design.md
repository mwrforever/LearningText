## 2. 搜索 UI（批次①）

### 2.1 快速打开（Cmd/Ctrl+P，FR-SEARCH-01 的文件名形态）

- 居中浮层（工作台之上遮罩层，非路由）：输入框 + 文件名模糊匹配结果列表（≤10 条，走既有 `searchQuery` 通道、`nodeTypes: ['file']`）；键盘 ↑↓ 选择、Enter 打开（`openFile` 既有链路，image 走图片预览路径见 §8）、Esc 关闭；aria 规范同 M3/M4（role=listbox/option + aria-activedescendant）。
- 输入去抖 200ms（本地常量，不进设置）；空关键词展示最近打开（§3.3 数据源，FR-AUX-02 与快速打开共用浮层——**裁决 D3**）。
- 菜单「快速打开」启用（M4 disabled 占位），accelerator 不变。

### 2.2 全局搜索面板（FR-SEARCH-01/02/03）

- **树栏三态视图切换**（裁决 D2）：树栏新增视图态 `tree | search | trash`（trash 见 §3.1）——工具栏搜索框（或菜单 Cmd/Ctrl+Shift+F）触发切入 search 态：顶部关键词输入 + 类型过滤（全部/HTML/目录，走 `filters.nodeTypes`）+ 结果列表。
- 结果项：文件名（nameSnippet 高亮）+ 虚拟路径 + 正文片段（bodySnippet 高亮，`ranges` 码元区间着色，**渲染器只按区间着色不收 HTML**——M2 spec §6 既定契约）；点击 → 定位打开（树侧展开至该节点 + `openFile`；预览联动既有链路）；「在树中显示」次级动作（关闭搜索态并展开选中）。
- 分页：默认 limit 50，底部「加载更多」（offset 递增；`truncated` 提示）；结果计数展示（total）。
- Esc 退出搜索态回树；搜索态下树数据不销毁（切回保持展开态——expanded Set 保留）。

### 2.3 搜索域 deferred 顺手清（TASK.md 触发条件达成）

- MatchIn 双源声明收口（`MatchInSchema` + `z.infer` 派生）；片段高亮码元展开字符（İ 类）策略评估——UI 层按区间 slice 前做 NFC 归一对照，若仍偏移则该类字符片段区间截断显示（展示级降级定档，不追求码点完美）；搜索测试细化批次随触碰顺手清。

## 3. 辅助功能（批次②）

### 3.1 回收站 UI（FR-AUX-01）

- 树栏 trash 态视图（D2 三态之一）：工具栏「回收站」入口切入；列表列 = 名称/原路径/删除时间（`deleted_at` 既有列）；项内操作 = 还原（`vfs:restore`）/彻底删除（`vfs:purge`，**二次确认**：应用内确认弹窗 `ConfirmDialog`，M8 起取代原生 confirm）；顶栏 = 关键词过滤（前端本地过滤，不发新查询通道）+ 清空回收站（`purge` 全量，**强确认**——应用内确认弹窗文案含条目数「将彻底删除 N 个节点，不可恢复」，裁决 D4；M8 起取代原生 confirm）；还原撞名（`E_VFS_DUPLICATE_NAME`）toast 呈现。
- **新增 `vfs:listTrashed` 通道**（裁决 D5）：`{ } → TrashedNodeMeta[]`（`NodeMeta` + `deletedAt`），服务层新增单 SELECT（`deleted_at IS NOT NULL`，复用行映射）；契约入 shared/vfs-contract，preload 具名包装，两道校验照旧。
- trash/restore/purge 成功后的广播与树/搜索态刷新链沿用 M3 语义（`trashed/purged/restored` 事件既有）；回收站态下收到 `restored` 广播重拉列表。

### 3.2 最近打开与工作区恢复（FR-AUX-02）

- **记录点**：`openFile` 成功打开文件时写入 `recent.opened`（去重置顶、≤20 条、字段 `{ nodeId, virtualPath, name, openedAt }`）；trash/purge 该节点时同步剔除。
- **快速打开空态复用**（D3）：浮层空关键词展示最近打开列表。
- **工作区恢复**：`workspace.tabNodeIds`/`activeTabNodeId` 随标签操作（open/close/activate）写入 settings（v3，D6）；**启动恢复**——装配链在树首拉完成后按 `tabNodeIds` 顺序逐个恢复（节点已不存在——trash/purge 过——静默跳过并修剪记录；全部失效则空态），激活位恢复 `activeTabNodeId`。恢复走既有 `openFile`（含大文件确认/图片路径），**5–50MB 的 confirm 在启动恢复路径自动放行**（恢复意图明确，不弹窗——裁决 D7）；恢复完成后一次性写入修剪后的 workspace 域。
- 设置页提供「启动时恢复工作区」开关（v3 `workspace.restoreOnStart`，默认开）。

## 4. 设置页与备份（批次③）

### 4.1 settings schemaVersion 3（裁决 D6）

```ts
SettingsSchema = z.strictObject({
  schemaVersion: z.literal(3),
  preview: { debounceMs },            // 既有
  editor: { autoSaveMs },             // 既有
  shell: { layout },                  // 既有
  appearance: z.strictObject({        // 新增（FR-AUX-03）
    theme: z.enum(['light', 'dark', 'system']),      // 默认 'system'
    editorFontSize: z.number().int().min(12).max(24), // 默认 14（编辑器字号，FR 字面「字号」归编辑器域）
  }),
  backup: z.strictObject({
    autoEnabled: z.boolean(),         // 默认 true（每日启动自动备份）
  }),
  recent: z.strictObject({
    opened: z.array(RecentEntrySchema).max(20),       // §3.2
  }),
  workspace: z.strictObject({
    tabNodeIds: z.array(z.number().int()),
    activeTabNodeId: z.number().int().nullable(),
    restoreOnStart: z.boolean(),      // 默认 true
  }),
});
```

- **v2→v3 迁移例程**沿用 v1→v2 范式（补默认域、原子回写、info 一次；不识别版本 warn 回退）。
- **写入策略**：recent/workspace 高频域与既有全量 get/set 通道并存——仍走 settingsSet 全量（≤20 条小数据，tmp+rename 原子写无性能面）；标签操作节流（300ms 尾沿合并写，避免快速切换连写，裁决 D8）。

### 4.2 设置页形态（裁决 D9）

- **全屏覆盖视图**（工作台之上，非模态非路由）：左侧分组导航（外观/编辑器/备份/维护）+ 右侧表单区，顶部「← 返回」；应用入口 = 状态栏「设置」钮 + 菜单「设置…」（Cmd/Ctrl+逗号，新增菜单项）。
- 表单控件即改即存（受控组件 + settingsSet，失败 toast 回滚显示）；Esc 不关闭（防误触，显式返回）。
- **外观区**：主题三选（亮/暗/跟随系统）；编辑器字号（数字输入 + 即时预览）。
- **编辑器区**：去抖时长（100–2000ms 滑块）、自动保存间隔（1000–60000ms 滑块）——既有 v2 键的 UI 入口（此前仅桥可改）。
- **备份区**：自动备份开关；手动「立即备份」钮；备份列表（时间+大小）+「还原到此点」（强确认后走 §4.4 restore）；`backup:done` 广播刷新列表。
- **维护区**：「重建搜索索引」钮（M2 spec §7.1 修复例程——v2 对账不平或用户自修复触发，强确认 + 进度 toast）；「清空回收站」快捷入口（同 §3.1 语义）。

### 4.3 主题与字号机制（裁决 D10）

- **主题**（v0.3 修订为 shadcn 体系）：shadcn/ui 标准语义变量（`--background/--foreground/--primary/--muted/--accent/--destructive/…`，Tailwind v4 `@theme` 映射为工具类）+ **`.dark` 类切换**双主题（shadcn 惯例，tw-animate-css 动效 tokens 同源）；`system` 态经 `matchMedia('(prefers-color-scheme: dark)')` 监听解析为实际主题（解析结果驱动 `document.documentElement.classList.toggle('dark')`，不写 settings——settings 只存用户意图）；入口 `index.html` 首帧防闪（内联读 settings？不可——settings 在主进程。**首帧默认 light，装配后切换，闪变定档为已知边界**；不做 inline 脚本（CSP 无 script-src 'unsafe-inline' 面））。
- **CodeMirror 暗色**：引 `@codemirror/theme-one-dark`（精确版本计划期实查锁定，纯 JS 无依赖）作为 dark 语法主题；light 沿用 `defaultHighlightStyle`；主题切换 = EditorView 重建（会话 state 的扩展集含主题——切主题全标签 view 重建，doc/undo 在 state 中保留）。
- **字号**：CM `EditorView.theme({ '&': { fontSize } })` 动态扩展——字号变更同走 view 重建（与主题同机制，一次重建覆盖两者）。

### 4.4 备份本体（§3.3 / NFR-06，裁决 D11）

- **自动备份**：每日首次启动（备份文件名日期 ≠ 今日即触发）在开库迁移完成后执行：`db.checkpoint`（WAL 合并，A.4-9 空闲语义——启动期即空闲）→ 复制 db 文件至 `<dataDir>/backups/lt-YYYYMMDD-HHMMSS.db` → 滚动保留最近 7 份（超出删最旧）→ info 日志；`backup.autoEnabled = false` 跳过自动（手动仍可用）。
- **通道**（docs/03 §7.1 规划落地）：`backup:create`（手动，同自动流程强即时）、`backup:list`（文件名+大小+修改时间数组）、`backup:restore`（`{ fileName }`）——restore 语义：**校验目标文件可打开且 `PRAGMA integrity_check` 通过 → 复制替换当前库文件（先 checkpoint + 关库）→ `app.relaunch() + app.exit(0)`**（重启后加载还原库）；渲染层强确认（「将覆盖当前全部数据并重启应用」）。
- **`backup:done` 广播**：备份完成后通知渲染层刷新列表（主→渲染事件，可辨识联合照 `VfsChangedBroadcast` 先例带 `{ rev? }` 不需要——纯通知 `{ fileName }`）。
- 错误码：新增 `E_BACKUP_FAILED`（复制/校验失败）、`E_BACKUP_NOT_FOUND`（restore 目标不存在）；`E_BACKUP_CORRUPT`（integrity_check 不过）。错误码演进在 errors.ts 统一登记。

## 6. 滚动同步（批次⑤，FR-RENDER-06）

- 协议按 M3 spec §7.2 既定设计落地：父→子 `postMessage({ type: 'lt:scroll-ratio', ratio })`；子→父 `postMessage({ type: 'lt:scroll-report', ratio, anchorText })`（opaque origin，`'*'` targetOrigin 同 css-swap 先例）。
- **编辑器→预览**（父→子）：EditorPanel scroll 事件（既有 onScroll 会话回写链路）节流 ~100ms → 计算滚动比例 → iframe.contentWindow.postMessage；预览接收器注入扩展监听（`lt:scroll-ratio` 与 `lt:css-swap` 并列，Task 9 注入机制复用）→ `window.scrollTo(0, ratio * (scrollHeight - clientHeight))`。
- **预览→编辑器**（子→父）：接收器内监听 scroll → 上报比例 + 锚点文本（可视首行文本快照）；EditorPanel 经 `TabSessions` 查锚点在 doc 中的行（`indexOf` 全文匹配首处，锚点失效静默忽略）→ view scrollTo 行位置。
- **双向防回环**：同步执行中的相对滚动不再上报（时间窗 ~150ms 抑制，裁决 D13）；开关——预览工具栏「滚动同步」切换钮（默认开，**不进 settings**——会话级偏好，裁决 D14）。
- 已知边界照 M3 §7.2 定档：启发式在复杂布局下有偏差，不追求像素级；`pre/code` 按行精确映射不做（YAGNI，首版通用启发式）。

## 7. 导入导出（批次⑥，FR-IO-01/02）

### 7.1 导入（FR-IO-01）

- **入口**：菜单「导入…」启用 + 树工具栏「导入」钮 → 主进程 `dialog.showOpenDialog`（`openDirectory` + `multiSelections`，用户选磁盘目录/多文件）→ 渲染层确认弹层：目标父目录（树选中上下文，默认根）+ 重名策略三选（跳过/重命名/覆盖，默认跳过）→ 发起 `io:import`（invoke：`{ sourcePaths, targetParentId, conflict }`）。
- **服务**（`src/main/io/` 新建，M0 预留目录）：遍历磁盘树 → 节点计划（含 mime 推导复用 `vfs/mime.ts`）→ **分批事务写入**（每批 ≤200 节点或 ≤16MB 内容，A.5-4 交互预算外的大批量剥离——分批本身就是 A.4-6 合并单事务的例外面，宪法 A.5-5「M0 可先以分批事务替代」的兑现；utility process 不做——批次间让出事件循环已保 UI 响应，裁决 D15）；单文件 >50MB 跳过并计数（写侧上限一致）。
- **进度与取消**：`io:progress` 广播（主→渲染，事务批次间发：`{ importId, phase: 'scanning' | 'writing', done, total, currentPath }`，B.3-4 事务提交后发）；取消 = `io:cancel` invoke（置取消标志，当前批次完成后停止，已写入节点保留并广播）——**裁决 D16**。
- **重名策略**：跳过（同名活节点存在则该节点跳过计数）；重命名（`name (2).ext` 递增后缀）；覆盖（trash 既有同名后写入——复用软删除语义，回收站可找回）。目录撞名时合并（进入该目录继续）对三策略一致。
- **源根不物化（澄清注，2026-09-21 Task 12 评审钉死）**：所选目录本身不建为节点，其**内容**按上方重名策略合并进目标父目录之下（多选源根逐一合并入同一目标）——目录撞名合并语义的自然延伸，属钉死既有实现读法，非需求变更。
- **结果**：`{ imported, skipped, failed }` 计数 toast + 详情（失败清单含原因）经结果面板/剪贴板导出（简化：toast 汇总 + 控制台明细，裁决 D17）。

### 7.2 导出（FR-IO-02）

- **入口**：树选中节点（file/dir 皆可）→ 菜单「导出…」/树工具栏「导出」→ 主进程 `dialog.showOpenDialog`（openDirectory 选目标目录）→ `io:export`（`{ nodeId, targetDir }`）。
- **服务**：子树遍历 → 逐节点写磁盘（目录 mkdir、文件 BLOB→file，进度同 §7.1 广播复用 `{ exportId, ... }`）→ **`vfs://` 引用改写**：对 `text/html` 文件内容中 `vfs://local/<path>` 形态引用改写为导出根下的相对路径（按源节点与引用节点的共同祖先计算 `../` 相对链；引用目标不在导出子树内→改写为 `#`（失效占位）并在结果计数中报告，裁决 D18）；`content` 为 NULL 的文件原样导出。
- **完成**：toast「导出完成：N 个文件 → <目录>」+「打开目录」动作（`shell.openPath`——B.5-4 白名单仅约束 `openExternal`，openPath 不涉网络面，裁决 D19）。
- 写磁盘冲突：目标已存在同名文件 → 直接覆盖（导出目录是用户显式选择的目标，预检弹目录占用确认一次）。

## 8. 图片预览（批次⑦，FR-EDIT-04）

- `openFile` 非文本分支改造：`image/*`（png/jpg/gif/webp/svg——mime 推导既有）与 `audio/*` 节点 → **不开编辑标签、不进 TabBar**，直接切换 PreviewPanel 的展示源（`selected` 语义回归：Workspace 增 `previewNode` 独立态——激活标签驱动 + 图片选中驱动双源，裁决 D20）；PreviewPanel 按 mime 分支：html 走既有 iframe 链路、image 走 `<img src=vfsUrl>`、audio 走 `<audio controls src=vfsUrl>`（浏览器原生「系统组件」能力，保真）。
- 其余二进制（非 image/audio）维持 M4 toast 拒开语义。
- 图片节点的「打开」不产生脏/保存管线面（只读）；树上图片节点选中高亮（树栏 `aria-current` 语义扩展到非标签选中——与 M4 的 selectedId=activeId 锚并存：新增 `previewOnlyNodeId` 弱选中态，裁决 D20 附则）。
